📡 Connect from SSH on the iPhone

github.dev on the phone is a browser app, so GitHub opens a passkey / mobile sign-in page. Codespaces have no public SSH IP. You SSH through gh codespace ssh, which needs GitHub CLI on the phone (Blink), not Termius alone.

🚫 Why Termius-only fails

Termius wants host + user + key. A Codespace is not zany-train.github.dev:22. GitHub builds a tunnel with your GitHub token, then talks to sshd inside the container. That tunnel is the gh CLI. Put gh on the iPhone, then SSH.

Saved browser URL (passkey path): 🔗 codespace-url.html

1️⃣ Once on the Mac (PAT so the phone skips passkey)

  1. GitHub → Settings → Developer settings → Personal access tokens. Create a token with Codespaces access. Copy it once. Do not commit it.
  2. Keep zany-train running (or gh cs ssh will start it): 
    gh codespace list
# name looks like: zany-train-p9wx45qrxq3rr5p

2️⃣ iPhone app: Blink Shell

App Store: Blink Shell. It can run gh. Termius cannot, unless you SSH to a Mac that already has gh (jump host, last section).

  1. Install Blink. Open a shell tab.
  2. Install GitHub CLI (Blink package name may be gh): 
    pkg update
pkg install gh
gh --version
    If pkg has no gh, download the linux-arm64 binary from cli/cli releases and put it on $PATH.
  3. Sign in with the token, not the Safari passkey flow: 
    gh auth login --with-token
# paste the PAT, then Ctrl-D
    ✅ Pass: gh auth status shows rifaterdemsahin. No passkey page.
  4. Open the Codespace over SSH: 
    gh codespace list
gh codespace ssh -c zany-train-p9wx45qrxq3rr5p
    If you omit -c, Blink shows a list. Tap/enter zany-train. ✅ Pass: prompt is something like vscode@codespaces- or @rifaterdemsahin ➜ /workspaces/codespaces-ai-agents.
  5. You are in the VM. Same as the github.dev terminal, without the editor: 
    cd /workspaces/codespaces-ai-agents
agy
# or
grok
    Logins you already did stay in ~/.agy and ~/.grok on this machine.

⏳ First gh codespace ssh can take a minute if the VM was Stopped — it starts it. Rebuild the container once after sshd was added to .devcontainer if SSH is refused.

3️⃣ Optional: Termius via your Mac

Only if you want Termius’s UI and a Mac is on the same network / Tailscale.

  1. Termius host = your Mac. User = your macOS user. Key = your Mac SSH key.
  2. Remote command (or type after login): 
    gh codespace ssh -c zany-train-p9wx45qrxq3rr5p

✅ You are connected when

You seeMeaning
Safari passkey / accounts.google / github.com login page 🚫 Still in the mobile browser. Close it. Use Blink + gh cs ssh.
Termius “connection refused” to *.github.dev 🚫 Expected. That hostname is HTTPS VS Code, not sshd.
gh: command not found in Blink 🚫 Install gh in that app first.
Prompt inside /workspaces/codespaces-ai-agents ✅ SSH session. Run agy or grok.

Proof screens for the agents: ✨ agy · 🤖 grok. Stop the VM when you hang up: gh codespace stop -c zany-train-p9wx45qrxq3rr5p.

📡 Tunnel is GitHub CLI, not a public port. No tokens on this page.
