💻 Desktop vs 📱 iPhone browser

What happens
💻 Desktop URL loads VS Code for the Web. GitHub session is usually already in the browser. Terminal → agy / grok.
📱 iPhone Safari Same URL works after you request the desktop site. Sign-in often opens a passkey sheet or a second mobile login page. After that, the editor is cramped but usable.
📡 iPhone SSH No VS Code UI, no passkey page on every open. Terminal only. See iphone-ssh.html.

🔐 Passkey on the phone is GitHub proving it is you in Safari. It is not Grok/agy login. Those stay inside the VM (~/.grok, ~/.agy) once you have authorised them once in zany-train.
