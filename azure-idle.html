☁️ Azure: wake on request, sleep when idle

Yes, you can — but Azure has no single “Codespaces” button for grok/agy. Closest: a small UK South VM that starts when you hit a URL and deallocates when SSH is idle. HTTP scale-to-zero (Container Apps) will not run those TUIs.

🧩 Pick a shape

A. B-series VM + start URL (recommended for grok/agy) Keep one tiny VM deallocated. Shortcut on the iPhone calls az vm start. Termius connects. A cron deallocates after N minutes with no SSH. Disk holds ~/.grok.
B. DevTest Labs Autostart at 18:00, autoshutdown at 23:00. Clock, not “idle”. Fine for evenings. Policies cap spend.
C. Container Apps scale-to-zero Wakes on HTTP, billed at zero replicas. Wrong tool for an interactive TUI. Right tool for a remote MCP HTTP server.
D. Delete the whole VM Cheapest idle. You lose the disk unless it is Azure Files / a snapshot. Recreate from a custom image on each request. Coldest start.

▶️ Shape A — start on request

On a machine already az login (or a Function with a managed identity):

Start (pay CPU)az vm start -g deliverypilot-rg -n grok-idle --no-wait
Wait until SSH is upaz vm wait -g deliverypilot-rg -n grok-idle --created && az vm get-instance-view -g deliverypilot-rg -n grok-idle --query instanceView.statuses
Deallocate (stop CPU bill, keep disk)az vm deallocate -g deliverypilot-rg -n grok-idle

iPhone: Shortcuts → “Get contents of URL” hitting an Azure Function that runs start. Then Termius to the VM’s public IP. Do not leave 22 open to the world — restrict to your IP or use Tailscale and no public SSH.

Idle destroy (on the VM, cron every 5 minutes):

If nobody logged in for 20 min, deallocate selfwho | grep -q . || az vm deallocate -g deliverypilot-rg -n grok-idle

⚠️ That one-liner is a sketch. You need a managed identity on the VM, a real idle window (last sshd login, not a single who), and you should deallocate not az vm delete if you want grok/agy sessions to survive. Built-in Azure “auto-shutdown” is a clock (e.g. 23:00), not SSH-idle.

🔌 MCP on Azure

Azure does have MCP: the Azure MCP Server (agents can list resource groups, Key Vault names, etc.). Host a remote MCP with Container Apps (HTTP, scale to zero — this part is request/idle). That is complementary to a VM that runs agy. Do not expect Container Apps to replace the Codespace TUI.

💷 Cost vs Codespaces vs Hetzner

You already pay the Azure subscription. A B-series in UK South, deallocated 20+ hours/day, can beat a 24/7 Hetzner box. It will not beat GitHub Pro included hours if you already stop zany-train. Disk of a stopped VM still bills. Full delete + snapshot is cheaper idle, slower wake.
