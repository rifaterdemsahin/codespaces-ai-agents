📋 Key to the phone: Downloads → WhatsApp → Termius

Use this every time you need the Azure grok-idle key on the iPhone. AirDrop is cleaner. WhatsApp to yourself as a Document (the zip) also works. Never a group chat.

1️⃣ Mac — put files in Downloads

Export./scripts/export-grok-idle-key.sh

Creates:

  • ~/Downloads/grok-idle.pem — import this in Termius (iOS needs the extension)
  • ~/Downloads/grok-idle.txt — same bytes; open, Select All, Paste Key
  • ~/Downloads/grok-idle-termius.zip — send this on WhatsApp as a Document

Fingerprint must stay:

SHA256SHA256:NA0Ra24KU1/8YJnJbds1VgLyG9pdH34VIrWzv2VKcFQ

2️⃣ WhatsApp — to yourself only

  1. Open WhatsApp on the Mac (or Files → share).
  2. Chat with yourself (or “Starred” / your other number). Not a group.
  3. Attach Document → grok-idle-termius.zip. Not a photo, not “file as media”.
  4. Send. On the iPhone: tap the zip → Share → Save to Files (On My iPhone).
  5. Files → unzip → you should see grok-idle.pem and grok-idle.txt.

3️⃣ Termius — Import, never Export

⚠️ “Export Key” with the authorized_keys bash snippet is the wrong screen. That tries to push a public key to the VM. Ubuntu has no password, so it fails. The Mac already put the public key on the box. You only need the private key in Termius.

  1. Keychain → if a key named grok-idle exists, delete it (it is empty).
  2. Keychain → + → Import from file → grok-idle.pem. Or + → Paste Key → open grok-idle.txt → Select All → Copy → paste. The text must start with BEGIN OPENSSH PRIVATE KEY.
  3. Label it grok-idle. After save it must show fingerprint SHA256:NA0Ra24KU1/8YJnJbds1VgLyG9pdH34VIrWzv2VKcFQ. If Termius says “Private Key is empty”, the import did not take — paste instead.
  4. Host: Address 40.120.63.5, port 22, user azureuser, key grok-idle (the one you just imported).
  5. Connect. If it asks to trust the host, Accept (SHA256:q9tOqtThKfhVSiJMdEmktR1us3SRcG+On/BoT+vbMYs).

4️⃣ After import

  • Delete the WhatsApp message and the zip from Files.
  • Delete ~/Downloads/grok-idle* on the Mac.
  • WhatsApp backups can keep the zip — prefer AirDrop next time if iCloud/WhatsApp backup is on.

⚠️ This is a private key. WhatsApp E2E to yourself is acceptable for a one-shot move. Do not commit the key. It also lives in Key Vault as grok-idle-ssh-private-key.
