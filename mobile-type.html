⌨️ iPhone 14 Pro Max · do not type in VS Code web

⌨️ Codespaces in the phone browser is a bad keyboard

The green-button UI is desktop VS Code in Safari. The iOS keyboard covers the terminal, has no Esc/Ctrl/Tab, and Smart Punctuation breaks code. Do not type prompts in that tab. Use Termius, or paste. Azure VPS is too expensive — not the fix.

One column, 44pt buttons, no sideways page scroll. Safari is fine for this site. Safari is the problem only inside *.github.dev.

✅ Fix that actually works

  1. Leave the Codespaces machine running (create it in Safari if you must). Close the VS Code tab. You will not type there.
  2. Open Termius (free Starter). SSH to this Mac, then jump in:
    On the Mac, after SSHgh codespace ssh -c zany-train-p9wx45qrxq3rr5p
    Termius has Esc, Ctrl, Tab, arrows above the keyboard. github.dev does not. Hops: 📋 Termius setup · 🆓 Free iPhone.
  3. Type the prompt in Termius, or in Notes → copy → paste into Termius. Paste is faster than the VS Code web editor.

🩹 If you must stay in Safari

  1. AA in the address bar → Request Desktop Website (once, to find Code → Codespaces).
  2. Rotate to landscape. More rows above the keyboard.
  3. Settings → General → Keyboard: Smart Punctuation off, Auto-Correction off, Auto-Capitalization off. Otherwise " becomes “ ” and commands fail.
  4. Write the prompt in Notes. Select All → Copy. Tap the Codespaces terminal → Paste. Do not compose in the VS Code box.
  5. Hide the file tree (tap the menu) so the terminal is full width.
  6. Not the GitHub iOS app. Share → Open in Safari.

⚠️ A Bluetooth keyboard is the only way the web workbench feels normal. Without one, Termius still wins.
