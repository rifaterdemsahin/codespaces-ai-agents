📱 How to test this from your phone

Do this on the iPhone itself, in Safari (not Chrome, not the GitHub app). You will open this site, start a 2-core Codespace, log Grok and Antigravity in with device codes, run one prompt, then stop the machine. Already have a github.dev tab? 🟢 After green button.

🧭 Prep (once, before any test)

  1. Use Safari. Chrome on iOS will not share GitHub / X / Google cookies with the Codespaces workbench the way Safari does.
  2. Turn Private Browsing off. Device-code logins need cookies that Private Browsing throws away.
  3. Settings → Battery → Low Power Mode off. iOS otherwise freezes the Codespaces tab while the container builds (several minutes).
  4. Settings → Display & Brightness → Auto-Lock → 5 minutes (or Never while you test). Plug the phone in if you can.
  5. Stay on Wi-Fi. First Codespace create pulls the Ubuntu image plus grok and agy installers.
  6. In Safari, sign in to these three sites and leave the tabs open: github.com as rifaterdemsahin, grok.com / X with SuperGrok or X Premium+, and Google with the Antigravity account. Pass: each site shows you already logged in, no password prompt.

The GitHub iOS app cannot host the VS Code workbench. If the app opens, tap the share sheet → Open in Safari.

🌐 1. Test this documentation site

  1. Open https://rifaterdemsahin.github.io/codespaces-ai-agents/
  2. Confirm the title Codespaces that run AI agents, then tap iPhone test in the nav to return here. Pass: both pages load over HTTPS, text is readable, cards stack, no horizontal page scroll.

🟢 2. Open a 2-core Codespace

  1. Open github.com/rifaterdemsahin/codespaces-ai-agents
  2. Tap AA in the Safari address bar → Request Desktop Website. GitHub hides Code → Codespaces on the mobile layout. Pass: you see the green Code button, not only a clone URL.
  3. Tap Code → Codespaces → Create codespace on main (or Resume if one already exists).
  4. If GitHub asks for a machine size, pick 2-core. Do not pick 4-core.
  5. Wait. First create is often 3–8 minutes. Keep Safari in the foreground. Do not switch to another app — iOS will suspend the tab and the editor may never finish loading. Pass: VS Code for the Web opens, file tree on the left, this repo’s files visible.
  6. Open a terminal: tap the hamburger (☰) → Terminal → New Terminal. The iOS keyboard will cover half the screen; drag the terminal pane up if you can.
  7. Run: 
    which grok agy az gh
grok --version
agy --version
    Pass: all four commands are on PATH and grok/agy print a version. If command not found, wait for post-create to finish or open a new terminal.

🤖 3. Test Grok (subscription, same phone)

Codespaces has no desktop browser. You approve the device code in a second Safari tab on this iPhone.

  1. In the Codespace terminal: 
    unset XAI_API_KEY
grok login --device-auth
  2. Long-press the printed URL → Copy. Also note the short code.
  3. Safari: new tab → paste the URL. Stay on the SuperGrok / X Premium+ account. Approve or type the code. Pass: the login page says success / connected.
  4. Switch back to the Codespaces tab. Then: 
    grok models
grok -p "Reply with READY and nothing else"
    Pass: grok models lists models, and the prompt prints READY. That is the live agent test.

If Grok asks for XAI_API_KEY, you are off subscription billing. Run unset XAI_API_KEY and login again. Do not pull xai-api-key from Key Vault unless you want pay-per-token.

✨ 4. Test Antigravity

  1. In the same terminal, run agy. It prints a Google authorization URL.
  2. Copy the URL → new Safari tab → sign in with the Google account that has Antigravity. Pass: the terminal leaves the login wait, or agy --version works afterward.

🔐 5. Optional — Azure Key Vault from the phone

  1. az login --use-device-code
    Copy the code, open microsoft.com/devicelogin in Safari, paste the code, sign in as info@deliverypilot.net. 
  2. ./scripts/kv-env.sh status
    Pass: it prints the vault name and OK lines for secret names. Values must not appear.

🛑 6. Stop the Codespace (required)

  1. Safari → the repo → Code → Codespaces → the three dots on your codespace → Stop codespace. Pass: status is Stopped. Idle hours no longer count against the GitHub Pro quota.

Next time: same URL → Resume. You must run grok login --device-auth again if this is a new codespace. A resumed one keeps ~/.grok.

🚑 If a step fails

What you seeFix
No green Code button AA → Request Desktop Website. Still missing? You are in the GitHub app — open in Safari.
Editor blank / “taking a long time” Safari kept the tab backgrounded. Foreground it, or reopen Codespaces → Resume.
grok: command not found post-create still running. Wait, then new terminal. Or export PATH="$HOME/.grok/bin:$HOME/.local/bin:$PATH".
Grok login page never loads in Codespaces Expected. Use grok login --device-auth and a second Safari tab.
Wrong X or Google account Safari tab → sign out → open the device URL again.
Codespaces blocked / quota GitHub Settings → Billing. Extra spend should be $0; included hours may be used up.
