💻 Test code to run in a Codespace

This is the real “are the agents working” check. Browser tests cannot log into Grok.

./scripts/system-test.sh -v
# same thing:
python3 tests/test_system.py -v

# after grok login --device-auth:
./scripts/system-test.sh --live -v

--live runs grok -p "Reply with READY and nothing else". Pass = the model printed READY.

JSON for this page (CI already does this):

python3 tests/test_system.py --json
  1. Open a 2-core Codespace from the repo (Safari → Request Desktop Website). Steps: iphone.html.
  2. Wait for post-create.sh. New terminal: ./scripts/system-test.sh -v. Grok/agy presence should PASS; Grok live stays SKIP until you log in.
  3. unset XAI_API_KEY && grok login --device-auth in one terminal, approve in a second Safari tab.
  4. ./scripts/system-test.sh --live -v — TestGrokLive.test_grok_prompt_ready must PASS.
  5. Optional: az login --use-device-code then rerun. Vault checks should PASS without printing values.
  6. Stop the codespace when finished.
