🎯 Why use this when you are mobile

The point is not “I love Codespaces” or “I love Azure.” The point is: you have a git repo, you are on an iPhone, and you want more than one agent to work on that same tree — Grok now, Antigravity now, others later — without a laptop session.

📱 The use case

  1. You are away from the desk. Phone only (Termius free, or Safari if you must).
  2. The work lives in one repository — not a paste into a chat website.
  3. You want several agents on that repo: plan with one, implement with another, review with a third.
  4. They must see the same files, git history, tests, and Key Vault helpers.
  5. When you lock the phone, the box should stop costing money.

That is why zany-train exists, why agy and grok were authorised on the same VM, and why the Azure idle VM / a cheap VPS are alternatives — same job, different landlord.

🚫 What this is not

Tempting shortcutWhy it fails this use case
ChatGPT / grok.com / Gemini in Safari No shared git tree. No tests. No git push. Each agent is a separate amnesiac tab.
GitHub Mobile editor Fine for a typo. Not a shell. Cannot run agy and grok on the same checkout.
Three agents on three laptops You are on a phone. Merge conflicts become your job.
Always-on VPS you forget to stop Works for Termius, but it is not “mobile evening use.” Idle-delete / Codespaces Stop is the budget.

🌱 Future: a base for agents

This repo is a seed, not a finished “agent OS.” The next layers that fit without changing the use case:

  • A standard ~/.config for MCP servers shared by every CLI.
  • One git remote, one branch policy, one ./scripts/system-test.sh all agents must pass.
  • Idle-delete / $5 budget so a forgotten session cannot become a bill.
  • The same Termius path: phone → shell → whatever agent is installed this month.
