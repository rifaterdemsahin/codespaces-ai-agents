🔌 Which ones have MCP setups

MCP = Model Context Protocol (tools for agents). Two different things: an official way to host/run MCP, vs a community MCP to control the cloud API. Any Linux VPS can run MCP yourself (npx / Docker). First-class product is rarer.

PlaceOfficial MCP product?What you actually get
Fly.io ✅ Yes fly mcp launch, fly mcp wrap, fly mcp proxy, plus a flyctl MCP server. Best “MCP hosting” of this list. Docs: fly.io/docs/mcp/
Azure ✅ Yes Azure MCP Server (manage Azure from an agent). Remote MCP on Container Apps / AKS / Functions. Not a cheap VPS SKU — see ☁️ Azure idle box.
GitHub Codespaces (zany-train) 🟡 Local, excellent MCP runs inside the codespace next to grok/agy (stdio). GitHub also has a GitHub MCP server. No extra host to buy.
Hetzner ❌ No first-party Community MCP for the Hetzner Cloud API. You install Node/Docker and run any MCP on the VPS yourself.
OVH / RackNerd / Contabo / Netcup / Oracle ❌ DIY only Plain Linux. Same as Hetzner: you run MCP processes. No vendor mcp launch.
DigitalOcean ❌ DIY Droplets are fine MCP hosts. No official MCP control plane.

For agy / grok on the phone, MCP on the same machine as the agent is what matters. Codespaces already does that. Fly is the one cheap-ish cloud with a real MCP deploy CLI.

🪰 Fly.io vs “cheapest VPS”

Fly can host grok/agy in lhr (London) — great from the UK. It is not the cheapest always-on box:

  • You pay for CPU/RAM time. Sleeping Machines can beat a VPS. A Machine left up 24/7 usually loses to Hetzner.
  • Dedicated IPv4 is extra. Without it, Termius cannot dial a public IP; you use fly ssh console from a Mac (same two-hop as Codespaces).
  • Need a volume if you want ~/.grok / ~/.agy to survive replaces.

Pick Fly if you already live there and want London + auto-stop. Pick Hetzner/OVH if you want Termius → IP:22 and a boring monthly invoice. Stay on Codespaces if you only work evenings and already pay GitHub Pro hours.

🧮 vs your Codespace

GitHub Pro included 2-core time is on the order of ~90 wall-hours/month. A Hetzner CX23 at ~€6 is cheaper than paying GitHub overage, and Termius becomes one hop. If you already stop zany-train when you leave, Codespaces can still be cheaper than a 24/7 VPS.
