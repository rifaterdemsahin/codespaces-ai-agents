  1. Stay in the github.dev tab. ☰ → Terminal → New Terminal.
  2. Paste this. It must print paths and version numbers. 
    pwd
which grok agy az gh
grok --version
agy --version
    ✅ Pass: pwd ends with codespaces-ai-agents, and grok/agy print a version. Fail: wait for post-create, then a new terminal, or export PATH="$HOME/.grok/bin:$HOME/.local/bin:$PATH".
  3. Repo checks (no Grok login needed): 
    ./scripts/system-test.sh -v
    ✅ Pass: tests OK, Grok-live is SKIP. Fail: read the first FAIL line — usually a missing file or network.
  4. Log Grok in (subscription, not an API key): 
    unset XAI_API_KEY
grok login --device-auth
    Copy the URL + code. Open them in another browser tab (or your iPhone). Approve. ✅ Pass: the login page says connected, terminal returns to a prompt.
  5. The actual agent test: 
    grok -p "Reply with READY and nothing else"
./scripts/system-test.sh --live -v
    ✅ Pass: the reply contains READY, and TestGrokLive.test_grok_prompt_ready is ok.
  6. Optional: Antigravity — run agy, open the Google URL, then agy --version.
  7. When you leave: GitHub → repo → Code → Codespaces → ⋯ → Stop codespace so zany-train does not burn idle hours.
