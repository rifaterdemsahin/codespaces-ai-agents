🛠️ What was done in this deploy

The GitHub repo existed but only had a two-line README. The real starter lived as devcontainer.zip plus untracked docs. Those files were turned into a working Codespaces environment and this site.

🔐 1. Azure Key Vault Used the existing az login as info@deliverypilot.net. Vault dp-kv-deliverypilot is reachable. Secret names were checked; values were never committed.
📦 2. Dev container Unpacked devcontainer.zip into .devcontainer/. Codespaces now installs grok, agy, Azure CLI, and GitHub CLI on a 2-core Ubuntu 24.04 image.
🔑 3. Secret helper scripts/kv-env.sh does device-code Azure login and can write a gitignored .env from the vault. XAI_API_KEY is opt-in so Grok stays on subscription billing.
🌐 4. GitHub Pages This index.html is deployed by .github/workflows/pages.yml on every push to main.
📱 5. iPhone test Step-by-step from an iPhone 14 Pro Max in Safari: site, Codespace, Grok, Antigravity, optional Key Vault, then Stop. Open the iPhone page.

Default billing path: GitHub Pro pays for the VM hours. SuperGrok / X Premium+ and Google pay for the agents via device login. An API key from Key Vault is optional and switches Grok to pay-per-token.

🗺️ Architecture

Codespaces has no desktop browser. First-time login for Grok, Antigravity, and Azure all use a URL + code that you approve on your phone.

▶️ How to run the agents

1. Open a Codespace

Repo → Code → Codespaces → Create on main. Pick 2-core. Wait for post-create.sh (installs grok and agy).

2. Log in with subscriptions

unset XAI_API_KEY
grok login --device-auth   # URL + code → phone, SuperGrok / X Premium+
agy                        # Google URL → phone
grok --version && grok models
agy --version

3. Work, then stop the machine

grok
# or
agy

git add -A && git commit -m "…" && git push
# GitHub → Codespaces → Stop, so included hours are not burned idle

Full subscription notes: SUBSCRIPTION.md. Cap extra Codespaces spend at $0 in GitHub Billing.

Vault dp-kv-deliverypilot in resource group deliverypilot-rg (subscription Azure subscription 1). No new vault was created.
